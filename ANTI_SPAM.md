# Anti-spam notes (read before posting)

1. **Give value first.** Teach something useful even if nobody clicks your link.
2. **One link max** unless the community allows a resources section.
3. **Disclose** if you made the product ("I built this…").
4. **Read the subreddit / IH rules** the same day you post — rules change.
5. **No cross-post blasting** the same text to 20 subs in one hour.
6. **Engage replies** for at least 24–48 hours; ghosting looks like spam.
7. **Don't buy upvotes** or ask friends to brigade.
8. If a mod removes you: apologize once, don't argue in public, fix the post.

If your post only works when the link is present, rewrite it.
